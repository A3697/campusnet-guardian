安装与首次使用
1. 默认安装到 D:\campusnet，也可在安装向导中更改目录。
2. 安装后通过开始菜单或桌面“工具”文件夹中的快捷方式打开。
3. 首次使用填写校园网上网账号、密码和运营商，再点击“保存并连接”。
   本安装包预设 https://huade.m5d.cn 深澜 Srun 校园网门户。
   其他学校的认证门户不保证兼容，请勿直接套用此预设。
4. 插好校园网线，或连接校园 Wi-Fi。无线接入可填写已保存的校园 Wi-Fi 名称。
5. 密码默认明文显示，可取消“显示密码”隐藏；密码保存在当前 Windows 用户的凭据管理器中。

日常操作
连接校园网 / 重新认证：立即尝试登录。
检测网络：检查账号、后台、策略与网络，结果显示在运行日志中。
账号设置：可选“保存设置”或“保存并连接”；取消不会保存修改。
重连策略：设置检查间隔、掉线等待时间和自动重连时段。
  时间按小时、分钟分别输入；支持多个时段，结束早于开始表示跨午夜。
  未勾选“限定自动重连时间”时全天可重连。
暂停重连：暂停 1–1440 分钟；“恢复重连”可提前结束暂停。
开启 / 关闭自启：控制登录 Windows 后是否启动托盘和后台监测。
  关闭自启不会立即停止本次运行的后台。

默认每 5 分钟检查一次；掉线后等待 60 秒再次确认并登录。
登录 Windows 时会先立即检查并尝试认证，再进入日常监测；暂停和时段限制仍有效。
首次安装尚未填写账号时，请先打开应用完成设置。

窗口可以缩小，内容可滚动。鼠标停在输入框上时，滚轮滚动页面，不会修改输入值。
日志未完整显示时先滚动页面；日志完整显示后滚动日志，到边界后继续滚动页面。
Tab 切换输入项，F5 刷新状态，账号页 Ctrl+Enter 保存并连接，策略页 Esc 取消。
关闭窗口会隐藏到托盘；图标也可能在任务栏右侧的小箭头中。
双击快捷方式会打开同一个窗口。

覆盖安装与卸载
覆盖安装保留安装目录下 profile 中的账号和重连配置，不覆盖已存在的 config.json。
安装和卸载会关闭该安装目录正在运行的主窗口和后台，请先保存设置。
可以在 Windows“已安装的应用”中卸载，也可运行安装目录中的 unins000.exe。
卸载会删除安装的程序文件、快捷方式以及属于该路径的自启项。
卸载保留 profile 中的个人配置、日志、暂停状态以及 Windows 凭据，便于重新安装恢复。
安装包自身不包含个人账号、密码或运行日志。

数据位置：安装目录\profile
  config.json        账号、门户、运营商与重连设置
  policy_state.json  暂停和恢复状态
  watch.log          后台检查及认证结果

本程序内置所需运行环境，不需要另外安装 Python。
