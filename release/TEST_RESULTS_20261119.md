# 2026-11-19 验证记录

版本：0.1.5+desktop.20261119.2。此版本在 .1 的基础上只修改更新下载的重试逻辑。

源码回归：454 项通过，1 项 POSIX 文件权限测试在 Windows 跳过。覆盖认证协议、重连策略、启动入口、托盘、配置保存、GitHub 更新、跨学校识别、触控板滚动和随机 MAC 重试。

滚动对照：向标准 Tk 文本控件和本应用发送相同的 Windows 原生 WM_MOUSEWHEEL 消息，验证 -1、-15、-31、-120 的向下滚动和细小向上滚动。旧绑定缺失时问题可复现，补上 TouchpadScroll 后恢复。另覆盖斜向和水平触控板事件、日志边界、账号页、策略页及数字输入值不变。

跨学校识别：旧学校仍可访问、当前学校不同、当前页面无法识别、公共探测站放行但校园网会话离线等场景均已验证。自动模式不会请求旧学校地址或向未知页面提交凭据；手动模式保留指定地址。物理网卡的网关、IP 和 MAC 优先于虚拟网卡。

随机 MAC：使用隔离模拟验证成功保留、认证失败恢复、修改中异常、等待超时、恢复失败记录、进程中断后的恢复、配置关闭、网卡或网关变化、授权取消、冷却时间和并发锁。原生修改命令在普通权限下被 Windows 拒绝，确认需要管理员授权。

经用户单独确认后，在本机有线校园网执行一次真实 MAC 更换与恢复，14 项检查通过。修改后确认处于未认证状态，识别出深澜 Srun 入口，由 D 盘已安装的程序完成认证并验证联网。随后恢复原 MAC、原驱动覆盖值和原重连策略，并再次确认网络可用。此测试验证了真实网卡操作、入口识别和安装版认证；找不到入口时的条件判断、冷却时间和异常回滚由隔离测试覆盖。

打包程序通过 12 项本地模拟认证检查，覆盖未知页面不发送凭据、错误密码、会话未确认、成功登录、动态接口、认证签名、避免重复登录以及更换控制器参数。源码包中 54 个应用和测试 Python 文件与工作区逐字节一致。

安装包通过 51 项检查，覆盖全新安装、覆盖升级、应用内更新交接、卸载、含空格和中文的路径、自启、快捷方式及个人文件保留。D 盘现有安装通过 19 项升级检查，确认程序哈希、账号和凭据、重连设置、自启及快捷方式；升级后网络可用，已按本次要求开启随机 MAC 重试。

用户已使用 UU 远程的电脑触控板回测，确认主窗口和重连策略可以正常上下滚动。

GitHub 下载实测发现连接多次提前结束，旧版在额外两次重试后放弃。.2 增加有进展时的继续重试，并保留 30 分钟和最多 32 次额外续传限制；自动化覆盖连续多次提前结束或读取异常后完整下载、范围校验及最终哈希校验。校验失败时不会安装残缺文件。
