# 2026-11-20 验证记录

版本：0.1.5+desktop.20261120.1。

用户报告认证后仍显示未连接，自动获取入口和手动填写地址均未成功。检查发现，设置页的识别按钮强制使用自动模式，忽略了尚未保存的手动输入；手动识别结果保存时也会丢失页面参数。联网检测还把正常网站的 HTTPS 跳转当成认证入口，认证后的状态只检查一次，并把门户状态未知归为离线。

这些问题已分别修正。手动模式只访问所填地址；自动模式仍只使用当前网络提供的跳转和网关，不扫描旧学校地址。普通网站只允许有限次跳转到其自身站点，外部认证跳转仍会保留。门户明确报告未认证时，不会被公共网页可访问的结果覆盖。

源码全量回归 476 项通过，1 项 POSIX 权限测试在 Windows 跳过。新增测试覆盖手动输入与识别结果保存、HTTPS 跳转、探测服务异常、外部认证跳转、会话状态未知、认证后延迟生效、重复认证抑制、JSON 响应和界面状态。首次运行的 16 项失败保留在本地排查记录中，修复后已通过。

本机有线网络的 6 项只读验证通过：自动模式确认网页可访问；手动地址成功获取并识别深澜页面；控制器参数保留；门户确认当前账号会话；手动模式确认网页可访问；已联网但没有认证跳转时不再记录为警告。本次检查未提交登录请求或修改网卡。

打包程序的 12 项本地模拟认证检查通过，包含错误密码、接口应答成功但会话未建立、成功认证、动态参数、账号签名和避免重复认证。更新与发布相关的 55 项检查通过。安装包内 55 个应用和测试 Python 文件与源码逐字节一致，默认配置不含个人账号和学校地址。

D 盘覆盖升级的 19 项检查通过，确认程序哈希、原有账号与凭据、配置、重连策略、自启、快捷方式、主窗口和后台进程。安装版主窗口实际显示“已连接，可以上网了”；在设置页输入真实认证地址并点击“识别此地址”，成功显示“深澜 Srun”和识别成功提示。取消设置后，个人配置文件哈希保持不变。
